# LLM Evaluation (평가)
> LLM 성능 측정 및 품질 관리 가이드

## 개요
LLM 평가는 모델의 성능과 품질을 체계적으로 측정하여 실무에서의 효용성을 판단하는 과정입니다.

## 평가 시 주요 고려사항
- **표준화된 평가 방법의 부재**: 명확히 정해진 평가 기준이 없어 목적에 맞는 평가 방식을 설계해야 함
- **품질 관리의 필요성**: 완벽하지 않더라도 지속적인 평가를 통해 품질 컨트롤 가능
- **사용 목적 중심의 평가**: 모델의 실제 사용 시나리오를 고려한 평가 설계 (RAI, 보안, UI 등)

## 단계별 평가 예시

### 1. 음성-텍스트 변환 (Speech-to-Text)
- **변환 정확도**: 음성이 올바르게 텍스트로 변환되었는지 평가
- **요약 품질**: 변환된 텍스트의 요약이 원본 내용을 적절히 반영하는지 확인

### 2. 정보 검색 및 질의응답
- **질의 변환 품질**
  - 사용자 질문을 검색 최적화된 형태로 변환하는 능력
  - Similarity 측정을 통한 변환 품질 평가
  - 키워드 검색 결과 개선도 측정

- **검색 성능**
  - **Precision**: 검색된 결과 중 관련 있는 결과의 비율
  - **Recall**: 전체 관련 결과 중 실제로 검색된 결과의 비율
  - **F1 Score**: Precision과 Recall의 조화평균

- **검색 효율성**
  - Threshold 설정을 통한 최적화
  - 응답 시간 및 리소스 사용량

### 3. 내용 요약
- **요약 완성도**: 핵심 내용이 누락 없이 요약되었는지 평가
- **요약 정확성**: 원본 내용과의 일치도 측정

### 4. 프롬프트 최적화
- **프롬프트 효율성**: 의도한 결과를 얻는데 적절한 프롬프트인지 평가
- **토큰 효율성**: 불필요한 토큰 사용을 줄여 비용 최적화 가능한지 확인

### 5. 최종 답변 품질
- **정확성**: 제공된 답변이 실제로 정확한지 평가
- **관련성**: 가져온 데이터를 기반으로 한 답변인지 확인

## RAGAS 평가 프레임워크

### 필수 구성 요소
| 요소 | 설명 |
|------|------|
| **Question** | 사용자가 입력한 질문 |
| **Context** | 검색을 통해 가져온 참조 자료 |
| **Answer** | 시스템이 생성한 최종 답변 |
| **Ground Truth** | 실제 정답 (기준값) |

### RAGAS 평가 지표
1. **Faithfulness**: 답변이 제공된 자료에 얼마나 충실한가
2. **Answer Relevancy**: 답변이 질문에 얼마나 적합한가
3. **Context Precision**: 검색된 자료가 얼마나 정확한가
4. **Context Utilization**: 제공된 자료를 얼마나 효율적으로 활용했는가
5. **Context Ranking**: 중요한 정보가 상위에 위치하는가

## 실무 KPI 지표

### 운영 중심 지표
- **Answer Rate**: 질문에 대한 응답 제공 비율 (거부 응답 포함/제외)
- **Fallback Rate**: 시스템이 적절한 답변을 제공하지 못한 비율
- **Satisfaction Score**: 사용자 만족도 점수
- **Rephrase Rate**: 동일 질문 재질의 비율
- **Relevance Score**: 답변의 관련성 점수

### 품질 및 보안 지표
- **RAI/Moderation Rate**: 부적절한 내용 필터링 비율
- **Security Score**: 보안 위험도 점수
- **Hallucination Rate**: 잘못된 정보 생성 비율

### 성능 지표
- **Token Count**: 평균 토큰 사용량
- **Latency**: 평균 응답 시간
- **Performance per Data Source**: 데이터 소스별 성능 차이

## 주요 평가 지표 상세

### Precision & Recall
정보 검색 시스템의 핵심 지표로, 검찰 수사를 예시로 설명:

| 조합 | 설명 | 예시 |
|------|------|------|
| **고정밀도 + 저재현율** | 확실한 경우만 선택 | 확실한 범죄자만 기소, 놓치는 사건 많음 |
| **저정밀도 + 고재현율** | 광범위하게 선택 | 많이 잡지만 무고한 사람도 포함 |
| **고정밀도 + 고재현율** | 이상적인 상태 | 완벽한 범죄 검거, F1 = 1.0 |

### F1 Score
```
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```
정밀도와 재현율의 균형을 측정하는 조화평균

### 자연어 처리 전용 지표

#### BLEU (Bilingual Evaluation Understudy)
- **용도**: 기계 번역 품질 평가
- **특징**: 생성된 텍스트와 참조 텍스트의 n-gram 일치도 측정

#### ROUGE (Recall-Oriented Understudy for Gisting Evaluation)
- **용도**: 요약 및 자연어 생성 시스템 평가
- **특징**: 재현율 중심의 평가 방식

### 실무에서 가장 활용도가 높은 방법
- **Cosine Similarity**: 벡터 간 유사도 측정을 통한 의미적 유사성 평가
- **Custom Score**: 특정 도메인이나 비즈니스 요구사항에 맞춘 맞춤형 평가 지표

## 평가 전략 권장사항
1. **다각도 평가**: 단일 지표보다는 여러 지표를 조합하여 종합 평가
2. **지속적 모니터링**: 실시간 성능 모니터링을 통한 품질 유지
3. **도메인 특화**: 사용 목적에 맞는 맞춤형 평가 기준 설정
