# CI/CD 파이프라인

## LLM과 CI/CD
- 지속적 통합과 배포
- 자동 빌드 및 테스트 : 유닛 테스트, 통합 테스트, 모델 성능 테스트
- 버전 관리 - Git for code, model version
- Docker/Kubernetes 사용한 컨테이너 화
- 성능/지표 게이트(퀄리티 게이트)
- EverGreen/canary 배포
- 롤백 전략
- "observability"
- criteria for going to prod
- collect user feedback
