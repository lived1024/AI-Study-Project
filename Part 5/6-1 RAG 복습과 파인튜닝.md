# RAG와 Fine tuning의 차이

## RAG - 예시) 

### 오픈북 테스트
#### 단점
- 제대로 된 책을 가져왔는지?
- 책 가져오는 방법을 계획해야함
- 시험장에 책 가지고 가야 함
- 책 없으면 망함
- 오래된 책이거나 선전용 정보라면?
#### 장점
- 새로운 책이 나오면 그것도 들고 가면 됨
- 정보를 믿을 수 있음
- 어디서 정보를 가져왔는지 증명 가능

### 텔레프롬프터
#### 단점
- 원고 생성 시스템 필요
- 생성 시스템이 복잡해짐
- 같은 분야일때 딱히 더 유리하지 않음
#### 장점
- 여러가지 분야 뉴스 가능
- 여러가지 모델(아나운서) 바꿔 사용 가능
- 여러가지 데이터소스 사용 가능


## Fine tuning

### 신입 교육
#### 단점
- 교육 시간이 오래 걸림
- 높은 비용
- 틀릴 수 있음
- 교과서가 필요함
- 교과서 질에 따라 결과가 다름
- 직원이 사표내면 다시 교육해야함
- 실시간이 아니라서 빠르고 에러날 확률이 적음
#### 장점
- 한 번 교육하면 파이프라인이 간단함

### 외워서 하기
#### 단점
- 오래 걸림
- 외운 것만 할 수 있음
- 날짜, 숫자같은 아주 자세한 디테일은 힘듦
- 여러 모델 테스트가 힘듦
#### 장점
- 깊은 전문성에 좋음
- 일관적인 말투 좋음
- 비슷비슷한 처리 내용에 좋음
- 훈련된 모델 하나만 있으면 됨됨
