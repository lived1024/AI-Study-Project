# Foundation model
물론 이런 경우는 거의 없음.

## Foundation model 만들때 순서
1. 데이터 수집 및 전 처리
  - 퀄리티있는 정보
  - 데이터 수집
  - 정리
  - 표준화
2. 어떤 모델을 사용할 것인가
  - 학습 방법 결정
3. 모델 평가 및 개선
  - 평가 지표: BLEU, ROUGE, CIDEr 등
  - 하이퍼파라미터 튜닝 (학습률, 배치 크기, 레이어 수 등)
  - 성능 개선을 위한 반복 학습
4. 배포 및 운영
  - 인프라 구축: API 서버, 모델 최적화, 관리 시스템
  - 사용자 환경: UI/UX, 튜토리얼, 문서화
  - 운영 도구: LLMOps, 모니터링, 성능 관리
5. 검증 및 홍보
  - 성능 검증: 벤치마크 테스트, 품질 평가
  - 시장 진입: 킬러 앱 개발, 사용 사례 확보


## 주요 모델 아키텍처
### Transformer (2017, Google)
- **핵심**: Self-Attention 메커니즘, 인코더-디코더 구조
- **장점**: 병렬 처리, 장거리 의존성 포착, 확장성 우수
- **영향**: 현재 대부분 Foundation Model의 기반

### BERT (2018, Google)
- **특징**: 인코더만 사용, 양방향 컨텍스트 이해(뛰어난 문맥 파악 능력) 
- **학습**: Masked Language Model + Next Sentence Prediction
- **용도**: 텍스트 분류, 질의응답 등 이해 중심 태스크

### GPT-3 (2020, OpenAI)
- **특징**: 디코더만 사용 (175B 파라미터)
- **학습**: 다음 토큰 예측 (Autoregressive)
- **용도**: 텍스트 생성, 번역, 요약 등 생성 중심 태스크

### 기타 주요 모델
- **T5**: 모든 NLP 태스크를 텍스트 생성으로 통일
- **GPT-4**: 멀티모달 능력 추가
- **PaLM, LaMDA**: Google의 대규모 언어 모델
